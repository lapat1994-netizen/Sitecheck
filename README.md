# SiteCheck for Android

Небольшое Android-приложение для проверки доступности сайтов через текущее сетевое подключение телефона (в том числе через AmneziaWG, если VPN активен для приложения).

## Что показывает
- Время TCP-подключения к HTTPS-сайту в миллисекундах (приближённый сетевой ping).
- HTTP-код ответа.
- Ошибку/тайм-аут, если соединение не удалось.

Важно: это не ICMP ping. Измерение включает установление TCP-соединения и может зависеть от DNS, TLS, маршрута и нагрузки. HTTP-код 403/404 означает, что сервер ответил, а не что сеть недоступна.

## Сборка APK без Android Studio
Проект содержит GitHub Actions workflow. Загрузите папку проекта в новый GitHub-репозиторий. Затем откройте вкладку Actions, запустите workflow **Build APK** и скачайте артефакт `SiteCheck-debug-apk` после завершения сборки.

Для локальной сборки нужен JDK 17+ и Android SDK:
`gradle assembleDebug`

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.
